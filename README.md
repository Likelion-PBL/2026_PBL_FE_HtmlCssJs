# 2026 프론트엔드 PBL (React) 1-4주차 예시 코드 저장소

React 트랙을 위한 실습 레포지토리입니다.  
본 레포지토리는 HTML, CSS, JavaScript의 기초를 웹 페이지로 직접 구현하는 데 집중하며,  
React 학습으로 넘어가기 전까지의 기초 체력을 다루는 것을 목표로 합니다.

## 레포지토리 목적

- 웹의 기본 구조(HTML)와 스타일링(CSS)을 직접 코드로 구현합니다.
- 마크업 → 스타일링 → 인터랙션 구조를 반복적으로 연습합니다.
- JavaScript를 통해 DOM 조작과 비동기 데이터 흐름을 자연스럽게 익힙니다.
- React 이전 단계에서 필요한 UI 사고력과 구조 감각을 기르는 것을 목표로 합니다.
- 본 레포지토리는 Vanilla 기반 커리큘럼(1~4주차)까지만 포함합니다.
- 5주차 이후 프레임워크(React) 학습은 별도의 레포지토리에서 진행됩니다.

## 주차별 학습 내용

### 1주차: HTML & CSS 핵심

| 항목 | 내용 |
|------|------|
| **학습 키워드** | 시맨틱 HTML, Box Model, CSS 기본 속성, Flexbox 기초 |
| **PBL 미션** | HTML/CSS로 나만의 자기소개 카드 만들기 |

### 2주차: CSS 레이아웃 & 반응형 설계

| 항목 | 내용 |
|------|------|
| **학습 키워드** | Flex/Grid 심화, Position(relative/absolute), Media Query, CSS 우선순위 |
| **PBL 미션** | CSS 레이아웃으로 아기사자 명단 대시보드 만들기 |

### 3주차: JavaScript 기초 & DOM 조작

| 항목 | 내용 |
|------|------|
| **학습 키워드** | 변수/함수, 배열·객체, DOM 선택/조작, 이벤트 처리 |
| **PBL 미션** | JavaScript로 아기사자 명단을 추가, 삭제하는 인터랙티브 대시보드 만들기 |

### 4주차: JavaScript 비동기 & 데이터 흐름

| 항목 | 내용 |
|------|------|
| **학습 키워드** | 비동기 처리 개념, Promise, async/await, fetch, 배열 메서드(map/filter) |
| **PBL 미션** | 외부 데이터를 불러와 명단을 갱신할 수 있는 인터랙티브 아기 사자 대시보드 만들기 |


|------|-----------|
| 1-2주차 | `index.html`, `style.css` |

## 예시 코드 확인 방법

각 주차별 예시 코드는 **브랜치**로 분리되어 있습니다.

| 브랜치명 | 설명 |
|----------|------|
| `week-1` | 1주차 기본 과제 예시 |
| `week-1-bonus` | 1주차 보너스 과제 예시 |
| `week-2` | 2주차 기본 과제 예시 |
| `week-2-bonus` | 2주차 보너스 과제 예시 |
| `week-3` | 3주차 기본 과제 예시 |
| `week-3-bonus` | 3주차 보너스 과제 예시 |
| `week-4` | 4주차 기본 과제 예시 |
| `week-4-bonus` | 4주차 보너스 과제 예시 |

### 브랜치 전환 방법

```bash
# 원하는 주차의 브랜치로 전환
git checkout week-1        # 1주차 기본 과제
git checkout week-1-bonus  # 1주차 보너스 과제
```
